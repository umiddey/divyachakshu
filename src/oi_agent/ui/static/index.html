Discord bot that audits local repos with OpenCode.

Set up OI

This takes about five minutes. You will:

  1. Install OpenCode (the AI harness) and sign in
  2. Create the Discord bot and invite it
  3. Pick channels and repo folders to watch
  4. Start OI in the background
